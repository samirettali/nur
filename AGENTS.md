# AGENTS.md

Personal [NUR](https://github.com/nix-community/NUR) repository (samirettali/nur).
Consumed by the dotfiles repo (`~/dev/dotfiles`) via the `nurPkgs` specialArg.

## Structure

- `default.nix` — wires every package: `<name> = pkgs.callPackage ./pkgs/<name> {};`.
- `pkgs/<name>/` — one dir per package: `default.nix` (derivation) + `update.sh`
  (executable bump script). Some packages vendor extra files (lockfiles, patches).
- `lib/`, `modules/`, `overlays/` — reserved NUR names; `modules/home-manager` is
  currently empty.

## Adding a package

1. Create `pkgs/<name>/default.nix` and an executable `pkgs/<name>/update.sh`.
2. Wire it in `default.nix`.
3. Build with `nix-build -A <name>`.

## Updating

`./update-all.sh` runs every wired package's `update.sh` and commits each bump
as `<pkg>: <old> -> <new>` with upstream compare/release links in the body.
It requires a clean working tree and stops on the first failure or dirty state.

## Commits

- Automated version bumps: `<pkg>: <old> -> <new>` (generated by update-all.sh — don't reword).
- Manual changes: Conventional Commits, e.g. `feat(<pkg>): add package`,
  `chore(<pkg>): update to <version>`.
